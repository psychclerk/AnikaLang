Why AnikaLang

Everything You Need,
Nothing You Don't

A complete toolkit for building real desktop applications without the complexity of traditional languages.

📝

Clean Modern Syntax

Write code with def, if { }, for in, and = assignment. No verbose keywords — just clean braces, rejoin() for strings, and readable logic.

🪟

Native GUI Framework

Build real desktop apps with 190+ widget functions — windows, tabs, grids, trees, rich-text editors, code editors with syntax highlighting, and more, all powered by wxPython.

📊

ML & Statistics

Train 22 machine learning algorithms, run 30 statistical tests (t-tests, ANOVA, regression), and create 12 chart types — all with simple function calls via scikit-learn, scipy & matplotlib.

🤖

AI & RAG

Chat with LLMs, generate embeddings, and build retrieval-augmented generation pipelines over PDFs. Works with Ollama or any OpenAI-compatible API — rag_ingest_pdf(), rag_query().

🗄️

Database Built-In

SQLite support out of the box with full-text search (FTS5). Create tables, run queries, manage attachments, and index documents — no external libraries needed.

📄

Office Documents

Create and edit Word (.docx), PowerPoint (.pptx), and Excel (.xlsx) files programmatically with 50+ dedicated functions for paragraphs, slides, charts, formulas, and formatting.

🌐

Web & Email

HTTP GET/POST with custom headers, SMTP email sending, IMAP inbox fetching, HTML rendering in WebViews — full internet capabilities built in.

🔊

Voice & Translation

Text-to-speech with system voices or Google TTS. Translate between 100+ languages with batch support, language detection, and offline TTS export.

⚡

Compile to Python

Run python main.py --compile app.fms to transpile your AnikaLang script into standalone Python code. Run it directly — no interpreter needed at deploy time.

Get Started

Up and Running in 30 Seconds

No Python needed. No dependencies to install. Just download and run.

1

Download from GitHub

github.com/psychclerk/anikalang/

Download code.zip for Windows

2

Extract to a folder like c:\anikawx\

install python 3.12

run pip install requirements.text

run python main.py projects/ide.fms

3

Create your first script

win = ui_window("Hello", 300, 200) ui_mainloop(win)

Save as hello.fms

4

Run your script

run python main.py path/to/script.fms

Or run it from the IDE. To compile: anikalang.exe --compile hello.fms
