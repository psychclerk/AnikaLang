Pro Tip — AnikaLang 1.2 Syntax
These libraries use v1.2 syntax: def name() { } for functions, x = value for assignment, if cond { } for conditionals, and rejoin() or + for concatenation (no & operator). Function calls are case-insensitive.
⚠️
Note on Built-in Conflicts
These libraries do NOT redefine built-in functions (abs, sqrt, sin, upper, lower, trim, replace, split, etc.). The mid() function is 0-indexed (like Python slicing). All 139 utility functions are added to the global namespace when you include the module.
